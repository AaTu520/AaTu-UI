# AaTu UI

客户端 HUD、字体、属性面板、经验条与受伤回放。

## 成品

Minecraft 1.21.1。

- NeoForge [aatu-ui-1.0.0.jar](artifacts/neoforge/aatu-ui-1.0.0.jar)

[HUD 设置与字体](GUIDE.md)

## 构建

使用 JDK 21，在仓库根目录执行 `.\gradlew.bat assemble -x test`。
